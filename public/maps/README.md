# Limites municipais de referência — Goiás

`goias-municipios.geojson` é uma cópia integral do conjunto de 246 municípios de Goiás disponibilizado por Geodata BR.

- Fonte: https://github.com/tbrugz/geodata-br
- Arquivo: https://raw.githubusercontent.com/tbrugz/geodata-br/master/geojson/geojs-52-mun.json
- Origem declarada pelo projeto: IBGE.
- Licença declarada: Creative Commons CC0 1.0 Universal. Cópia em `LICENSE-geodata.md`.
- Obtido em 15/10/2026. A data de obtenção não equivale à data de atualização dos limites.

Uso: orientação regional quando o mapa de ruas não estiver disponível. As geometrias representam municípios; não representam os imóveis ou as parcelas das planilhas e não substituem levantamento cadastral aprovado.
